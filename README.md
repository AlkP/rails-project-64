## проект "Коллективный блог"

Минималистичный проект для обмена мнениями. С возможностью оставлять комментарии и "лайкать" понравившиеся посты.

---

### требования

* Ruby 3.4.4
* Node.js v20.19.6
* yarn
* SQLite for local

### Setup

```bash
make setup
```

### Run

```bash
make start
```

### Linter

```bash
make lint
```
